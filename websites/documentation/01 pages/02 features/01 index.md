# Features

Eight reasons webette feels simple and powerful.

## For everyone

### A site you can open and edit
Start from the included example site, then tweak folders and files until it feels like yours.

### No back office required
Your site lives in folders and files, not in a dashboard.

### Live preview while you work
Run `serve` and watch changes rebuild and refresh locally.

### Publish at the right time
Use `draft`, `unlisted`, and `ignore` to control what appears.

## For tinkerers

### Enriched markdown
Use classes, heading ids, and internal links like `collection:/entry:/block:`.

### Smart images
Automatic variants, inline `block:` usage, and the `image` helper.

### Navigation and indexes
Navigation Plan (`navigation.webt`), Automatic Index Pages, and Index Overrides.

### Templates and plugins
Wrapper, layout, partials, helpers, plus plugins with safe outputs.

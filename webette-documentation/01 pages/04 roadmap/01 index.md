# Roadmap

This page lists future directions that are not implemented yet.  
Short and lightweight, just to show the path.

## What we want to tackle next

- Finish the documentation site and update the demo links.
- Improve navigation and index building for complex sites.
- Make configs and templates easier to reason about.
- Grow the plugin and starter ecosystem.
- Make webette easier to run and ship as a simple app.

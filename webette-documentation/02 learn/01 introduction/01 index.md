# Introduction

Welcome to **Learn**.

This section is the guided path through webette.  
It is written to get you from zero to a working site, one small step at a time.

Along the way you will learn how to:

- build and preview your site locally
- organize content as collections, entries, and blocks
- add navigation, templates, and plugins when you need them

Start here: [Quickstart](collection: learn, entry: quickstart).

## The core idea

The first thing to understand is that webette reads your folders as a site structure.

- Collections are top-level folders.
- Entries are subfolders.
- Blocks are files inside entries.

## What you get

- A static site (HTML + assets) you can host anywhere.
- A JSON model export in `_public/_model` if you want to debug or understand how webette organized your site.

If you want exact behavior and options, use **Reference**.

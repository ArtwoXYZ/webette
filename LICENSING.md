# Licensing Overview (Webette)

This repository is **multi-licensed**. Different parts of the project are covered by different licenses.

For the full text of the Apache-2.0 license, see `LICENSE`.

## TL;DR

- **Source code** (the webette tool itself, templates, build scripts, tests): **Apache License 2.0**.
- **Documentation** (written docs such as Markdown/text): **Creative Commons Attribution 4.0 International (CC BY 4.0)**.
- **Artwork / mascot / brand artwork** (images, icons, illustrations, SVG/PNG, etc.): **Creative Commons Attribution 4.0 International (CC BY 4.0)**.
- **Name and logos as identifiers**: see **`TRADEMARKS.md`** (copyright license ≠ trademark permission).

## How to interpret this

- If a file contains its **own** license notice or header, that notice applies to that file.
- Otherwise, use the categories above (code vs documentation vs artwork).

## Where to find the full license texts

- Apache-2.0: `LICENSE`
- CC-BY-4.0: `LICENSES/CC-BY-4.0.txt`

## Notes

- Creative Commons licenses are intended for creative works (docs, images, etc.) rather than software code.
- CC BY 4.0 does **not** grant patent or trademark rights.

## Welcome to the Playground

This **collection** is a set of small, hands-on exercises.
You will edit files, rename folders, and see what changes in the generated site.

Keep `serve` running while you play:

```bash
bun run serve -v website-example
```

Some pages may ask you to run a one-shot build:

```bash
bun run build -v website-example
```

## What's inside

- [Edit your text](entry: Edit your text) : edit a paragraph and watch live reload.
- [Rename an entry](entry: Rename an entry) : rename an **entry** folder and observe the new URL.
- [Reorder with numbers](entry: Reorder with numbers) : change `01/02/03` prefixes to reorder **blocks**.
- [Add a Link](entry: Add a Link) : write a markdown link using `entry:` / `collection:`.
- [Insert an image inline](entry: Insert an image inline) : render an image inline from markdown.
- [Ignore a Block](entry: Ignore a Block) : use `ignore.webt` to keep a file scanned but not auto-rendered as a **block**.
- [This is just a Draft](entry: This is just a Draft) : see how `draft.webt` behaves in serve vs build.
- [Unlist an Entry](entry: Unlist an Entry) : see how `unlisted.webt` removes a page from indexes (but keeps it routable).
- [Custom Layout for an Entry](entry: Custom Layout for an Entry) : use a dedicated layout for one **entry**.
- [Go Further](entry: Go Further) : grab links to docs, starters, plugins, and more.

Go in order, or jump around.

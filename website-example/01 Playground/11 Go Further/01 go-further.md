# Go Further

## Nice work

You just completed the whole **Playground** **collection**.

You can keep playing as long as you want: edit files, rename folders, break things, fix them, and see how **webette** reacts.

You've already learned the basics:

- how **webette** turns folders into **collections**, **entries**, and **blocks**
- how `serve` and `build` behave
- how to rename and reorder content without special tooling
- how drafts, unlisted pages, and custom layouts fit into the workflow

This demo is not exhaustive though. **webette** can do much more, and the best part is: it's still the same idea.  
Files and folders first, then you choose how far you want to go.

## Links

- [Official documentation](https://docs.webette.org)  
  The place to learn everything that wasn't covered in the demo: configuration, templates, Markdown features, and all the "how does this work?" details.

- [Starters store](https://store.webette.org/starters)  
  Ready-to-use starter projects to bootstrap a new **webette** site, with a structure that matches a specific goal (blog, docs, portfolio, etc.).

- [Plugins store](https://store.webette.org/plugins)  
  Extra features you can add to your build pipeline (and sometimes your **model**) without changing the way you write content.

- [Sites built with **webette**](https://webette.org/showcase)  
  Inspiration, real-world patterns, and proof that the "folders first" approach scales.

- [Support the project](https://webette.org/donate)  
  If you like **webette**, this helps keep development moving (and helps me make a living).

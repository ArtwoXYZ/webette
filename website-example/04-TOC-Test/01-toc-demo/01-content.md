# TOC Plugin Demo

This entry demonstrates the TOC plugin functionality.

## Section 1: Getting Started

Welcome to the TOC plugin demo. This section shows how the plugin works.

### Subsection 1.1: Basic Features

The plugin automatically generates a table of contents from your markdown headings.

### Subsection 1.2: Configuration

You can configure the plugin in your `webette.config.ts` file.

### Subsection 3.1: Marker Files

Use `toc.webt` files to enable TOC selectively.

### Subsection 3.2: Global Mode

Enable TOC for all entries with `forAllEntries: true`.

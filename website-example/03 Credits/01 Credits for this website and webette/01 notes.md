# Credits for this website and webette

## Webette

webette is an open source tool for building websites from folders and text files, and this demo
site is part of the project. The documentation, examples, and site content are written with a
simple tone and a focus on clarity. The tool, the docs, and this demo share the same project
license, unless stated otherwise.

Created by **Artwo**. **webette** and the **bebette** mascot are part of the same project,
and they share the same license unless stated otherwise.  
https://artwo.xyz

Fonts used in the demo:
- **F1.8** (mono display, bundled in the project)
- **system-ui** and system monospace fallbacks (depends on the OS)

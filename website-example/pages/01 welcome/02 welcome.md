# Welcome to webette

This might be your very first **webette site**.

This demo site is here to show you what **webette** can already do:  
how it reads folders, detects content, builds navigation, and turns a simple directory tree into a fully working website.

Take a look around.
Open folders.
Edit files.
Break things if you want.

> webette won't mind.
